A deadpan one-star review of gravity, the everyday essential that never takes a day off: a real complaint filed in earnest against a thing that cannot be fixed, with the sting arriving in the last few words.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-star-essential-out python3 main.py
cat /tmp/one-star-essential-out/entry.txt
```

The program writes a single line of at most 160 characters to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
